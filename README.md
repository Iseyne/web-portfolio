# Personal Portfolio

A personal portfolio website created as part of an academic assignment. It showcases information about me, my skills, projects, and contact details.

**[Visit the website](https://iseyne.github.io/web-portfolio/)**

## Features

- Responsive layout for desktop and mobile devices.
- Light and dark themes.
- Navigation between page sections.
- Project cards with repository links and technology badges.
- Skills section organized into categories.
- Contact links to GitHub, Telegram, and email.

## Technologies

- **HTML5** — page structure and semantic markup.
- **Tailwind CSS** — utility-first styling.
- **CSS3** — component styling, responsive design, animations, and color themes.
- **GitHub Pages** — website hosting.

## Projects

The portfolio currently features the following projects:

- [Archiver-Huffman](https://github.com/Iseyne/Archiver-Huffman) — an educational Rust archiver implementing Huffman compression.
- [NetAnalysys](https://github.com/Iseyne/NetAnalysys) — a Rust-based graph analyzer with a terminal user interface.
- [Marline](https://github.com/Iseyne/marline) — a Rust deduplication library I contribute to.

## Running Locally

To run the website locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Iseyne/web-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd web-portfolio
   ```

3. Start a local HTTP server:

   ```bash
   python3 -m http.server 8000
   ```

4. Open the following address in your browser:

   ```text
   http://localhost:8000
   ```

An internet connection is required to load Tailwind CSS from its CDN.
